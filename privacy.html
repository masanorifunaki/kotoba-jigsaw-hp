プライバシーポリシー

制定日：2026年9月28日
改定日：2026年10月31日

iOS アプリ「言葉ジグソー」と「ことねこ野球盤」（以下、2 つをまとめて「本アプリ」）での、利用者の情報の扱いを定めます。

収集する情報

本アプリは、利用者の個人情報を収集しません。アカウントの登録もいりません。開発者のサーバーはなく、本アプリから開発者へ情報を送ることもありません。

端末に保存する情報

本アプリは、次の情報を利用者の端末の中だけに保存します。保存した情報は、本アプリを端末から削除すると消えます。

言葉ジグソー

  • 解いた言葉と、解いた日時。次に出す言葉を選ぶためと、1 日の無料の数を数えるために使います。
  • 解説の 2 択で誤解のほうを選んだ言葉と、その日付。翌日のおさらいに使います。
  • 設定（前日のおさらい、猫の道案内、ことねこ夜行の音・揺れ・夜の深さ）と、前に選んだ遊び、前に案内した先生の猫。
  • 言葉の一覧の写し。通信できないときにも遊べるようにするために使います。

ことねこ野球盤

  • その日に終えた試合の数。1 日の無料の数を数えるために使います。
  • 一度使った技と、試合前の掛け合いを出した日。
  • 操作の設定（投げる輪の速さ、振る瞬間の目安）。

言葉ジグソーの「書いてから組む」で書いた字は、その問題の解説を閉じると捨て、端末に残しません。

通信

言葉ジグソーは、言葉の一覧を GitHub Pages（masanorifunaki.github.io）から取得します。この通信で、開発者が利用者の情報を受け取ることはありません。GitHub は、セキュリティのためにアクセス元の IP アドレスを記録します。記録の扱いは GitHub のプライバシーに関する声明に従います。

ことねこ野球盤は、App 内課金のほかに通信をしません。

App 内課金

どちらのアプリにも、300 円の買い切りの App 内課金があります。購入と復元は Apple の App Store が扱い、開発者は支払いの情報を受け取りません。購入したかどうかは端末に保存せず、起動するたびに App Store に確かめます。

Game Center

言葉ジグソーは、起動したときに Game Center へのサインインを求めます。サインインしなくても、同じように遊べます。本アプリは、スコアや実績を Game Center に送りません。Game Center の情報の扱いは、Apple のプライバシーポリシーに従います。

ことねこ野球盤は、Game Center を使いません。

友だちに出題する

言葉ジグソーの「友だちに出題する」を押すと、答えを伏せた出題カードの画像、問いの一文、App Store へのリンクを、iPhone の共有の画面に渡します。送るかどうかと送り先は、利用者が共有の画面で選びます。

解析・広告・追跡

本アプリは、利用状況の解析ツール、広告、利用者の追跡を使いません。カメラ・マイク・写真・位置情報も使いません。

このポリシーの変更

このポリシーを変えるときは、このページを更新し、制定日の下に改定日を書きます。

お問い合わせ

本アプリとこのポリシーについてのお問い合わせは、GitHub の Issues で受け付けます。
