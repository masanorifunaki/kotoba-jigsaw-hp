プライバシーポリシー

制定日：2026年9月28日

iOS アプリ「言葉ジグソー」（以下「本アプリ」）における利用者の情報の扱いを定めます。

収集する情報

本アプリは、利用者の個人情報を収集しません。アカウントの登録も不要です。

端末に保存する情報

本アプリは、次の情報を利用者の端末の中だけに保存します。これらの情報を開発者や第三者へ送信することはありません。

  • 解いた言葉と、解いた日時。次に出題する言葉を選ぶために使います。
  • 問題データの写し。通信できないときにも遊べるようにするために使います。

保存した情報は、本アプリを端末から削除すると消えます。

通信

本アプリは、起動時に問題データを GitHub Pages から取得します。この通信で、開発者が利用者の情報を受け取ることはありません。

GitHub は、セキュリティのためにアクセス元の IP アドレスを記録します。記録の扱いは GitHub のプライバシーに関する声明に従います。

解析・広告・追跡

本アプリは、利用状況の解析ツール、広告、利用者の追跡を使用しません。

このポリシーの変更

このポリシーを変更するときは、このページを更新し、制定日の下に改定日を記載します。

お問い合わせ

本アプリとこのポリシーについてのお問い合わせは、GitHub の Issues で受け付けます。
